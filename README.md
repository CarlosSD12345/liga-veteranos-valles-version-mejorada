# Liga Veteranos Vallès - Versión Mejorada

Esta es la base inicial del proyecto de la nueva versión mejorada de la web de la liga de veteranos del Vallès.

## Stack inicial
- Next.js
- TypeScript
- CSS modules / CSS global
- estructura preparada para evolución con Supabase

## Scripts
- `npm install`
- `npm run dev`
- `npm run build`
- `npm run start`

## Estructura inicial
- `app/` : páginas y layout
- `components/` : paneles reutilizables
- `lib/` : datos de ejemplo
- `types/` : tipado centralizado
- `supabase/` : estructura preparada para integración futura

## Próximo paso recomendado
1. conectar Supabase
2. crear autenticación para admin/delegados
3. migrar datos reales de equipos, jornadas y resultados
4. preparar panel de gestión completo
